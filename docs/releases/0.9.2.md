# PromptBridge 0.9.2 预发布

主应用 **0.9.2/build51**，沿用辅助组件 **3.1.0/build21**。适用于 macOS 14 及以上的 Apple Silicon Mac。

整框翻译默认使用 ⌥T。在「设置 → 翻译与浮窗」点击键位，录入新组合并保存，菜单与浮窗会显示当前可用的快捷键。组合被占用时可直接改选，原键仍可用。CLI 的外部编辑器键位由宿主管理。

本机已验证旧版偏好兼容、保存后重载、录入取消、跨进程键位占用、写盘失败回退与系统热键触发。偏好和界面专项通过 78/78，最终键名调整后专项复测通过 22/22。完整回归中的模型供应商表单场景未通过；真实宿主整稿替换、多布局切换和另一台 Mac 的首次安装仍待验证。

下载 ZIP 后解压并打开 PromptBridge。本版使用自签名证书，未经 Apple 公证。首次打开、权限与 CLI 配置见[安装说明](../installation.md)。
